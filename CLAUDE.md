# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Keeping the README current

After implementing any feature or behavior change, review [README.md](README.md) and update it if the change affects anything documented there — commands, environment variables, model usage, setup steps, costs, or behavior. Treat the README update as part of the feature, not a follow-up.

The README is **public-facing**: this is an open-source project, so the README is read by external users and contributors. Write it for that audience.

Because it's open source, the README **may include implementation/code details** (file paths, internal logic, config internals) where they help users or contributors understand the project — that information is not sensitive here. Do not, however, include secrets, tokens, or anything that should stay private.
